# 易经六爻占卜软件

这是一个基于Web技术的易经六爻占卜软件，包含完整的六十四卦数据库和卦象解读。

## 功能特点

1. **完整的易经六爻占卜功能**
   - 模拟传统铜钱摇卦
   - 完整的64卦数据库
   - 本卦和变卦解读
   - 变爻分析

2. **现代化用户界面**
   - 响应式设计，适配各种设备
   - 美观的铜钱动画效果
   - 清晰的爻序列显示
   - 详细的卦象解读

3. **实用功能**
   - 历史记录保存（使用浏览器localStorage）
   - 结果导出为文本文件
   - 键盘快捷键支持
   - 使用帮助文档
